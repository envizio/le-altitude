# Contributing

Issues and pull requests are welcome. For a bug report, include the steps to reproduce it, the expected and actual behavior, your phone and browser, and the FlySight firmware version. Do not post personal information or other secrets. Track files can show where you jump, so share them only if you are happy for them to be public.

For code changes:

1. Serve the folder locally (see the README) and check the change in a browser, with a FlySight where it touches Bluetooth.
2. Bump `CACHE` in `sw.js` and the matching `LE LIVE v` label in `index.html`, and add any new file the app needs to `FILES`.
3. Open a pull request with a concise description of the change and the checks you ran.
